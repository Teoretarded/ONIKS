# AN/SPY-6 (AMDR) and the Aegis fleet air-defence network

Role: not a weapon but the sensor/C2 layer that makes the carrier group's SM-6/ESSM defence coherent on screen.
AN/SPY-6 is Raytheon's next-generation AESA radar (fitted to Arleigh Burke Flight III and the Constellation
class); Aegis is the combat system that fuses every ship's radar picture into one shared fleet track, letting one
ship's sensor cue another ship's missile (Cooperative Engagement Capability).

## Specs

- SPY-6(V)1 array: four fixed faces, each built from Radar Modular Assemblies (RMAs), roughly 30x larger
  detection range than the legacy SPY-1D it replaces on new-build Burkes — [US Navy fact file](https://www.navsea.navy.mil/)
- Array face size: each RMA is a ~2 ft (0.6 m) cube; a full SPY-6(V)1 face is built from 37 RMAs —
  [Raytheon SPY-6 product page](https://www.rtx.com/raytheon/what-we-do/naval-radars/spy6)
- Detection range: officially undisclosed exact figures, described as able to track an object half the size and
  twice as far as SPY-1D — [Raytheon SPY-6 product page](https://www.rtx.com/raytheon/what-we-do/naval-radars/spy6)
- First fitted hull: USS *Jack H. Lucas* (DDG-125), commissioned 2023, first Flight III Burke —
  [US Navy commissioning release](https://www.navy.mil/)
- Aegis Combat System / CEC: links multiple Aegis ships' and aircraft's sensor tracks into one composite picture,
  letting a missile be guided using another platform's radar data — [US Navy Aegis fact file](https://www.navsea.navy.mil/)

## Visible parts / what it looks like in action, as a game system

- Physically: four large flat black array panels set into a ship's forward deckhouse (replacing the older raised
  SPY-1 octagonal panels), immediately recognisable as the newer Flight III silhouette versus the current Burke
  model.
- As a game mechanic rather than a physical prop, it's best shown the way Aegis/CEC actually works: a shared
  radar/track-fusion overlay across the carrier group's escorts — a detection made by one ship's radar becomes
  instantly available to every other Aegis-linked ship and its SM-6/ESSM battery.
- Visual language: a shared "track picture" HUD layer (extends the existing sensors/scan system) rather than a
  new unit — tracks a hostile contact and shows, distinctly, which ship's radar first acquired it and which
  ship(s) can now engage it off that shared track.
- No dramatic action shot exists (it's a phased-array radar, not a moving weapon); test and installation imagery
  is the extent of public photography.
