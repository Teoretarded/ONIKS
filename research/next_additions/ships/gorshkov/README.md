# Admiral Gorshkov class (Project 22350)

Role: Russia's newest general-purpose frigate — long-range strike, area air defence and ASW in one hull. Lead
ship *Admiral Gorshkov* commissioned 2018; the class is the natural coastal-defence-side counterpart to the US
Arleigh Burke/Ticonderoga already in the roster.

## Specs

- Length: 135 m — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Beam: 16 m — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Displacement: ~5,400 tonnes full load — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Speed: 29-30 knots — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Range: ~4,500 nautical miles — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Complement: ~180-210 — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)
- Armament: 16 universal 3S14 VLS cells (Kalibr/Oniks/Zircon), Poliment-Redut SAM system (32 cells), 130 mm A-192
  gun, Paket-NK torpedo tubes, Ka-27 helicopter — [Naval News class profile](https://www.navalnews.com/naval-news/2020/07/russias-project-22350-frigates/)

## Visible parts / what it looks like in action

- Sharply angular, radar-shaped superstructure typical of modern Russian frigate design, single enclosed mast
  carrying the Poliment phased-array panels (four flat faces, one per side).
- Flush deck-mounted VLS hatches forward of the bridge (the same 3S14 cell family as Kalibr/Oniks/Zircon already
  modelled) and a separate Poliment-Redut SAM cell block just behind them.
- Single 130 mm gun turret on the bow, a slim mast/funnel arrangement amidships, and a helicopter hangar/deck aft
  for a single Ka-27.
- Underway it has a low, lean profile with a moderate bow wave at speed; boarding photos show the same grey
  Russian-navy paint scheme and deck fittings as the game's other Russian hulls.
