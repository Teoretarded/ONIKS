# SSN-774 Virginia-class fast attack submarine (Block I/II baseline)

> **Correction (checked against the photos, 2026-09-25):** early Virginia boats have a cruciform (+) stern as in the photos; the X-stern text below does not apply to them.

## Dimensions and mass
- Length overall: 377 ft (114.9 m) (Block I–IV; Block V with the Virginia Payload Module is ~460 ft / 140 m — this profile is the pre-VPM baseline).
- Beam (hull diameter): 34 ft (10.4 m).
- Draft: ~32 ft (9.8 m|).
- Displacement: ~7,800 long tons submerged (~7,900 LT commonly cited).
- Crew: ~132 (officers + enlisted).
Sources: [Wikipedia, Virginia-class submarine](https://en.wikipedia.org/wiki/Virginia-class_submarine), [NAVSEA/Navy fact file, attack submarines](https://www.navy.mil/Resources/Fact-Files/Display-FactFiles/).

## Speed / propulsion
- 1x S9G pressurized-water nuclear reactor, 1 shaft, pump-jet propulsor (not an open screw).
- Max speed: officially "25+ knots" submerged; commonly cited unofficial estimate ~34–35 kt submerged, ~25 kt surfaced — treat any single number as approximate since exact speed is classified.
- Diving depth: officially "800+ ft" (classified exact figure; open literature often cites ~250+ m / 800+ ft).
Source: [Wikipedia](https://en.wikipedia.org/wiki/Virginia-class_submarine).

## Shape and layout (bow to stern)
- **Bow**: blunt, rounded, teardrop-derived bow housing the large spherical/conformal bow sonar array — no traditional torpedo tubes in the bow (torpedo tubes are angled amidships, not bow-mounted, to keep the bow sonar clear).
- **Sail (fin)**: single sail set well forward of amidships, low, hydrodynamically faired, no bow planes on the sail (Virginia-class uses bow planes retracted into the hull forward, not sail-mounted planes like Los Angeles-class) — hull-mounted "chin" bow planes fold flush against the hull.
- **Sail-mounted masts**: photonics masts (non-hull-penetrating, camera-based — no periscope tube through the pressure hull), radio/ESM antennas, snorkel — all retract into the sail when not in use.
- **Torpedo room**: forward, below/behind the bow sonar sphere, angled torpedo tubes (4x 21-inch) fire outward at an angle rather than straight ahead.
- **Vertical Payload Tubes / VLS**: forward section, 2x large-diameter Virginia Payload Tubes (each holding up to 6 Tomahawk missiles = 12 total) mounted vertically forward of the sail, flush with the hull, hatches only visible when open (Block I/II hulls; Block III+ replaced these with the 2-cell Virginia Payload Tube arrangement carrying more missiles per tube).
- **Hull form**: continuous cylindrical pressure hull with a smooth, low-drag outer casing; no large hull-mounted flank array bulges beyond the low-profile wide-aperture arrays (WAA) set along the sides.
- **Stern**: single shaft with a pump-jet propulsor (shrouded, not a visible open propeller), X-shaped stern control surfaces (not a cruciform + / cross layout — Virginia-class uses an X-stern for shallow-water maneuverability and if one surface is damaged), towed-array sonar fairing along the upper aft hull/stern.

## Moving parts
- Bow planes fold flush into the hull when not extended (no rotating masthead/rotating sensor domes on modern SSNs).
- Photonics masts rotate/elevate hydraulically but do not penetrate the pressure hull (unlike older periscopes).
- X-stern control surfaces (rudders/sternplanes) move independently, four surfaces at 45° offsets instead of a traditional cross.
- No externally visible rotating radar — submarines don't carry rotating air-search radar masts of the surface-ship type.

## Markings / colours
- Matte black anechoic-tile-covered hull (sonar-absorbing coating gives a slightly rough, non-reflective matte black finish, distinct from painted-steel gloss), hull number stencilled small in white/grey near the sail when surfaced, no large ship-name markings (submarines are minimally marked for signature reasons).

Note: exact top speed and max diving depth are officially classified; the figures above are the commonly cited open-source estimates with the disagreement flagged. Payload-tube configuration differs between Block I/II (2x 6-pack VPT) and later Blocks — description above is Block I/II which best matches "SSN-774" as the lead/name ship.
