# A-222 "Bereg", 130 mm self-propelled coastal artillery

Wheeled coastal-defence gun system: single 130 mm A-222 gun (derived from the naval AK-130) in an armoured
turret on an 8x8 chassis (MAZ-7910), used against ships and shore targets. Distinct from the missile systems
in this folder — this is a gun, not a missile launcher.

## Dimensions and mass

| | |
|---|---|
| Length (hull) | ~11.6 m |
| Width | ~3.13 m |
| Height | ~3.0 m (turret roof) |
| Wheelbase/axles | 4 axles (8x8), MAZ-7910 |
| Combat mass | ~43.7 t |
| Road speed | up to 60-70 km/h |
| Range | ~850-1,000 km (road, chassis fuel range) |
| Crew | 8 (2 in cab drive/command, remainder in turret/ammunition handling) |

Sources: [Wikipedia: A-222 Bereg](https://en.wikipedia.org/wiki/A-222_Bereg), [Military Today: Bereg](https://www.military-today.com/artillery/bereg.htm), [Army Recognition: A-222 Bereg data sheet](https://www.armyrecognition.com/russia_russian_missile_system_vehicle_uk/a-222_bereg_130mm_self-propelled_coastal_defence_gun_system_technical_data_sheet_specifications_pictures.html). Figures for max range and rate of fire vary between sources by a noticeable margin — treat as approximate.

## Shape and layout

Front to back: MAZ-7910 flat 8x8 cab (crew compartment) → long open chassis deck → enclosed armoured turret
toward the rear, mounting the single long 130 mm gun barrel (barrel length roughly 6+ metres, noticeably long
and thin compared to the tank-style turret body) centred on the turret front, with a distinctive slab-sided
turret shape and a rear turret bustle for ammunition. Small optical/fire-control sensor housing on the turret
roof. No missile canisters, no secondary weapons visible in most photos — a fairly spare silhouette compared
to Bastion/Bal.

## Moving parts

- **Turret**: traverses (full or near-full rotation, exact arc not confirmed).
- **Gun barrel**: elevates for indirect/long-range fire; single barrel, no autoloader details public.

## Colours / camouflage

Olive-drab solid colour in the available reference photos (see `images/`); no camouflage-pattern photos found
in this search.

## Disagreements / gaps

Only 3 free-licence photos were found on Wikimedia Commons for this system (all by the same photographer,
"Leonidl") — no over-the-horizon action shots, no drawings/blueprints located. Max gun range figures vary
between ~23 km (standard shell) and up to ~50 km (claims tied to guided extended-range ammunition); the higher
figure is not well corroborated. Deploy/stow timing not found in any public source.
