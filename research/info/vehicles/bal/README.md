# 3K60 Bal, coastal missile system (launcher + command vehicle)

Mobile coastal-defence anti-ship missile system firing the Kh-35/Kh-35U (Uran family) subsonic sea-skimming
missile, on the same MZKT-7930 8x8 chassis family as Bastion. A battery normally has 2 launcher (TEL) vehicles
(each with 8 missiles), a command-and-control vehicle, and support/loader vehicles.

## Dimensions and mass (MZKT-7930 chassis, shared with Bastion)

| | |
|---|---|
| Length | ~12.7 m (MZKT-7930 chassis; 11.2 m appears in some sources) |
| Width | ~3.1 m |
| Height | ~3.0 m (cab; launcher taller with canisters raised) |
| Wheelbase/axles | 4 axles (8x8) |
| Combat mass (launcher, loaded with 8 missiles) | ~43 t |
| Road speed | up to 60 km/h |
| Range | ~850-1,000 km (chassis fuel range) |
| Crew | launcher ~3; command vehicle crew larger (~5+) |
| Deploy time | ~10 minutes march-to-fire commonly cited (unofficial) |

Sources: [Wikipedia: 3K60 Bal](https://en.wikipedia.org/wiki/3K60_Bal), [Military Today: Bal-E](https://www.military-today.com/missiles/bal_e.htm), [Army Recognition: Bal-E data sheet](https://www.armyrecognition.com/russia_russian_missile_system_vehicle_uk/bal-e_3k60_ssc-6_sennight_mobile_coastal_defense_missile_system_technical_data_sheet_specifications_pictures.html). Deploy time and some mass figures are inconsistently reported between sources.

## Shape and layout (launcher vehicle)

Front to back: MZKT-7930 flat cab → chassis deck → 8 tubular Kh-35 canisters carried in two rows of 4,
angled upward (not flat like Bastion — Bal's launch tubes sit at a fixed elevated launch angle rather than a
single large erector pack of 2 big canisters). No large single erector arm; the canister rack itself is the
launch frame, elevating as a unit if adjustable, or fixed at a preset angle depending on variant. Small liaison
antennas on the cab roof.

Command vehicle: same MZKT-7930 cab, closed van body on the bed (no missile canisters), roof-mounted
communications/radar antennas, folded for travel.

## Moving parts

- **Missile rack**: 8 canisters raised together to launch angle (if the mount is elevating; some Bal launcher
  photos show a fixed near-level angle at rest that lifts before firing).
- Deployment/outriggers not consistently visible in photos; likely present but not as prominent as Bastion's.

## Colours / camouflage

Olive-drab and digital/blotch camouflage variants seen across Russian Navy coastal-defence brigades (Pacific,
Black Sea, Baltic fleets) — see `images/action_firing_*` for at-sea exercise photos.

## Disagreements / gaps

No public official deploy-time or exact elevation-angle figures found. Missile-rack elevation mechanism is
inferred from photos, not confirmed by a technical document.
