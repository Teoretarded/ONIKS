# Project 636.3 Kilo — drawings and video links

## Drawings / blueprints

- `profile_line_drawing.svg` and `profile_line_drawing_alrosa.svg` (in `images/`) are proper scale side-profile
  line drawings by Mike1979 Russia — the best geometry reference in this set, use directly for silhouette.
- [Naval Technology: Improved Kilo Class](https://www.naval-technology.com/projects/kilo/) — cutaway/spec description.
- [Federation of American Scientists: Kilo class](https://man.fas.org/dod-101/sys/ship/row/rus/636.htm) — profile diagram.

## Videos

1. "Rostov-on-Don submarine Black Sea Fleet" — search term; surfaced transit footage, good for sail and hull
   proportions.
2. "Kilo class submarine Kaliningrad launch" or "Varshavyanka submarine ceremony" — shipyard launch/christening
   footage, useful for full-hull-out-of-water shots (rare view).
3. Western navy shadowing footage ("Kilo class submarine surfaced Mediterranean") — search term; several such
   clips exist from NATO patrol aircraft/ship encounters.
